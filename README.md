Entry for the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) competition on make.fun: one joke about Monday mornings, 200 characters at most.

`main.ts` deterministically writes the entry to `/output/entry.txt`:

> My Monday alarm went off. My ambition hit snooze. My coffee went on strike.

Run it with `node main.ts`. No input, no randomness, no network, so every run produces the exact same bytes.

Gate: the entry is 75 characters, one line, inside the 1–200 character limit.
